UPGRADE STUDIO — первая рабочая версия

Файлы:
- index.html — главная страница
- styles.css — дизайн
- script.js — меню, анимации, фильтры, калькулятор
- render.yaml — конфигурация Render

Быстрый запуск локально:
1. Откройте index.html двойным кликом.

Публикация через GitHub + Render:
1. Создайте новый репозиторий, например upgrade-studio-site.
2. Загрузите в корень репозитория все файлы из этой папки.
3. В Render: New > Static Site.
4. Подключите GitHub и выберите репозиторий.
5. Build Command оставить пустым.
6. Publish Directory: .
7. Нажмите Create Static Site / Deploy.
